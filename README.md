# GoLangForDummies

Hi! I'm **samueldaone007** and I'm learning Go (Golang).

This repo is my public learning journal. I'm not an expert. I'm figuring things out as I go, and I'm writing everything down in plain, beginner-friendly **`.md` files** so the concepts are simple to understand.

## What's in here

- `hello/` — my first Go programs (starting from "Hello, World")
- `*.md` — simplified explanations of Go concepts, one topic at a time

## How I'm learning

I believe the best way to learn is to break big, scary topics into tiny, simple pieces. Every time I learn something new in Go, I'll add a short `.md` file explaining it in the simplest way I can.

If you're also learning Go, feel free to read along, suggest corrections, or open an issue if I got something wrong. We're all learning together!

## Getting started

Make sure you have Go installed:

```bash
go version
```

Then run any example:

```bash
cd hello
go run .
```
